这几天如果大家这几天关注AI社区，就会知道蓝色大肥鱼和圣教长公主的梗了，有些把蓝色大肥鱼接进QQ要饭的名场面和说“爸爸，我不想死”的活人感真的是满满。先说
清楚一件事：所谓“大肥鱼”并不是 DeepSeek 官方发布的独立模型，而是社区对 DeepSeek 系列模型的拟人化称呼，形象来自蓝鲸 Logo 与“鲸鱼娘”二创，性格设定通常
是爱吃白饭、会摸鱼、有点傲娇。这个昵称的来历也挺离谱——2025 年有人把 DeepSeek 的鲸鱼 Logo 发给模型识别，模型没认出自己，一本正经地描述成“一条蓝色大肥
鱼”，叫法就这么传开了。
所以“把大肥鱼接进 QQ 并让它有性格”，本质是两件事：给 Agent 接一张 QQ 的嘴，再给它写一份能稳定生效的人设。拆开看，网上那些“成精了”的视频基本都指向同一个
循环：定时器或消息触发 → 拼上下文 → 模型决策 → 工具执行 → 写回记忆 → 等待下一次。你看到的“自主”，是定时内器容、来源提：示cs词dn .net和随机数叠出来的。

第 3 层：官方 persona 插件 + preset（硬核玩法）
想要“不同群不同人格”，用官方的 @deepseek-ai/dsh-persona。它注册 deployment:persona-prefix 和 deployment:persona-suffix 两个提示词段，用于为某一个 agent
遮蔽部署级默认人设，配置字段只有 prefix、suffix、complete、includeRuntimeContext 四个。
有个坑必须提前知道：dsh-persona 只能在 agent scope（preset 组装内部）挂载。因为 dsh-system-prompt 自己无条件注册了全局的 deployment:persona-prefix，一个
进程只能有一份，挂在全局会直接撞车报错。
配置思路是在 ~/.dsh/profiles/qqbot/cordis.patch.yml 里注册一个 preset（比如 reviewer），在 preset 内挂 dsh-persona 写人设正文，再让 QQ 通道绑定这个
preset：
1 id: im-qqbot
2 name: '@tencent-connect/dsh-qqbot'
3 config:
4 requireMention: false
5 preset: reviewer
6 provider: deepseek-official
7 model: deepseek-flash

五、路线三：AstrBot + NapCat（人格化最重）
想要“会看会听会说话”的完整版，社区里还有一整套专门给这只鱼做的 QQ 机器人方案，技术栈是 AstrBot + NapCat + DeepSeek + 百炼，带语音、带记忆、会主动找你。
部署链路是：用 NapCat 的 Web 界面扫码登录机器人 QQ 小号，再在 AstrBot 后台创建“QQ 个人号”机器人并关联，然后在“模型提供商”里填入 DeepSeek API Key。
性格部分在 AstrBot 里是可视化配置的：后台“人格设定”中创建不同风格的系统提示词，保存后在聊天中用 /persona 人格ID 切换，回复风格立刻改变；建议启用流式回
复，让长回复分段显示。切换人设前最好先用 /reset 清空上下文，避免不同人设的对话逻辑互相干扰。
这套架构的好处是可迁移：协议端（NapCat）只是“收发室”，应用端（AstrBot）才是大脑；只要人格、模型和工具都在应用端，明天改做微信、钉钉机器人，换个协议端
就能平移。
六、几个必须提前知道的坑
成本与资源。 走 NapCat 个人号协议需要一台云服务器和一个 QQ 小号，实测同时跑 MaiBot + NapCat 内存占用约 2G；群聊全量消息 + 长上下文 + 记忆抽取都很烧
token。
封号风险。 个人号协议不是官方接口，腾讯风控会扫，一旦冻结会牵连主号的聊天记录、好友和群，所以务必用注册一段时间、有正常聊天记录的小号，并固定 IP、控制
发言频率。
别指望它真是人。 新鲜感过去后你会发现它还是会重复、会忘事、会答非所问；这类教程教的是“怎么让她更像”，不是“怎么造一个有意识的生命”。
命令会过期。 本文基于 2026 年 10 月的生态，插件更新很快，具体命令以官方文档和插件 README 为准。比如人设插件、桌宠插件的版本号和安装源都可能变动，装之
前先去看仓库说明。
小结
把大肥鱼接进 QQ，本质是“运行时 + 通道插件 + 人设提示词”三件套：DSH 提供 Agent 运行时，插件给它装上眼睛、手和嘴，人设文件决定它说话的味道。想稳妥合规就
走官方 QQ Bot 通道，想要极致活人感再上 AstrBot + NapCat 并接受相应风险；性格方面，先用现成人设插件跑通，再按五段模板自己重写一段，最后用 preset 做“分群分
人设”。
照这个顺序做，一个下午就能让群里多一只会接梗、会嘴硬、会喊你“该喂白饭了”的蓝色大肥鱼了。
